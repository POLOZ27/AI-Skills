# AI 作业检测

用本地开源模型（AIGC_text_detector，Apache-2.0）给作业打"AI 生成可能性"分数，并标出可疑段落。全程离线，学生作业不会上传到任何外部服务。

## 第一次使用

脚本在本 skill 目录的 `scripts/detect.py`。先确认依赖和模型已装好：

```
python -c "import torch, transformers"
```

如果报错，运行：

```
pip install -r <skill目录>/requirements.txt
python <skill目录>/scripts/detect.py --download
```

模型下载一次后（约 1.7GB，在 Hugging Face 缓存里），以后可以设置 `HF_HUB_OFFLINE=1` 完全离线运行。CPU 就能跑，不需要显卡。

## 检测步骤

1. 弄清老师要检测什么：单个文件、整个文件夹，还是粘贴的一段文字。支持 .txt .md .docx .pdf。
2. 运行脚本：
   - 单个文件：`python <skill目录>/scripts/detect.py "作业.docx"`
   - 整个文件夹：`python <skill目录>/scripts/detect.py "作业文件夹" --out "AI检测报告.md"`
   - 一段文字：先把文字写到临时 .txt 文件再检测（避免命令行引号和换行问题）
   - 语言会自动识别，中英混合时可用 `--lang zh` 或 `--lang en` 指定。
3. 把结果用中文讲给老师听：
   - 整体等级：高（≥85%）、中（60%–85%）、低（<60%）
   - 指出分数最高的几段，引用开头几句，方便老师对照原文
   - 文本过短（中文少于 150 字、英文少于 80 词）时，明确说结果不可靠
   - 批量检测时，先给汇总表，再列出"高"等级的作业

## 必须告诉老师的事

每次给结果都要提醒，不能省略：

- 这只是参考分数，**不能单独作为认定作弊或处分的依据**。
- 检测器会误判，写作规范、句式简单、非母语写作的学生更容易被误判为 AI。
- 学生把 AI 文本改写、换模型、故意加错字，都能让分数明显下降，所以"低"也不代表一定是自己写的。
- 建议的核实方式：看写作过程（草稿、修改记录）、和学生面谈让他讲解内容、对比该学生以往作业的风格。

不要用"该学生作弊了""这是 AI 写的"之类的断定说法，用"AI 生成可能性较高，建议进一步核实"。

## 输出示例

```
整体 AI 生成可能性：91%（高），语言：zh

| 段 | AI 可能性 | 等级 | 开头 |
| 1 | 95% | 高 | 随着科技的不断发展，人工智能已经深刻改变了… |
| 2 | 42% | 低 | 我记得那天下午放学后… |
```

## 限制

- 模型基于 2023–2024 年的 AI 文本训练，对更新的大模型效果可能下降。
- 只检测文本，不检测代码、数学公式或图片。
- 不做抄袭/查重比对，那是另一类工具。
